# ADR-0005：统一语言强制（term-lint + 双 hook + 门禁）

- 状态：已接受
- 日期：2026-06-25
- 相关：autotester ADR-0004（机制同源）；护栏 #4 #12

## 背景

LLM 在 Casey 里既写归一适配器、又草拟断言、又做编译——天然倾向造词、用 excel 里的野字段、把同一概念叫成五个名字。散文纪律（「请遵守术语表」）约束不住模型的命名行为（autotester 有两次现行违例实锤）。统一语言（DDD）若不机器强制，会被侵蚀成翻译损耗，裁定/报告/缺陷单各说各话。

## 决策

照搬 autotester ADR-0004 的机制，数据源换成 Casey 的 `CONTEXT.md`（两个限界上下文：loop-kit 通用子域 + Casey 核心域）：

1. **四列制术语表**（术语/中文译名/白话解释/弃用别名）是白名单 + 黑名单的唯一数据源；
2. **标记约定**：凡作为术语使用的词必须加粗或反引号，使其可被 `term-lint` 机器识别；
3. **三个执行点**：Stop hook 扫回合输出、PostToolUse hook 扫写入的 md/json、Quality Gate 扫 `GUARDRAILS.md` 与 `specPath`；命中弃用别名/未登记加粗英文术语/繁体字即红；
4. **造词先登记**：新概念先在既有学科（DDD→SRE→控制论→CI/CD→XP/BDD→ITIL）找映射，映射不到才造词且必须当场四列制补登记；
5. **中文一律简体**：`term-lint` 繁体检测命中即红，`term-lint:allow` 行豁免（仅用于必须举繁体例子的场合）；
6. **hook fail-open，门禁 fail-closed**：hook 自身故障不阻塞正常工作（lint 基础设施永不瘫痪会话）；门禁缺 `CONTEXT.md` 时报红。

## 后果

- 收益：裁定态、断言词汇、报告小节、缺陷单全仓共用一套术语；术语漂移在写入即被拦。
- 代价：每个新核心域术语需当场登记四列；引导期需把设计/计划里的既有用语回填进表（已在 P0/P1 完成）。
