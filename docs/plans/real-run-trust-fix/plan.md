# 真实运行信任修复

真实 SUT 录像在 2026-07-16 证明三个缺口：`run` 固定实例化 `r1` 会撞测试残留；搜索回车后立即扫描会把尚未收敛的目标列表判成 `none`；`run` 在 verdict 非全 `PASS` 时仍打印 `GREEN` 并退出 0。

本修复仅做三件事：增加显式且受限的 `--unique-name` 并透传到 replay；删除目标扫描最多等待 3 秒、唯一即继续、多目标立即拒绝；报告始终生成，但只有所有 intent 都为 `PASS` 时 `run` 才退出 0。裁定树、报告 schema、fake-SUT 与 loop 改革均不变。

零 SUT 回归只验证纯汇总函数和生产接线；发布、历史、CRUD 三链必须使用不同令牌重新在真实 SUT 录屏复验。
