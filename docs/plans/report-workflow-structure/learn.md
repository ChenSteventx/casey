1. **外部异构评审全阻时的诚实降级**：本轮 codex 额度耗尽（9:31 PM 重置）+ deepseek 未配 + pi 无法从 WSL shell 非交互驱动（cli.js 载入即挂、`--version` 都不出）——三条跨族路径全断。走 review 道 config 的末位同族兜底（Claude 子代理 ×2 fresh-context 对抗镜头），audit **明标非跨族 + 信任非对称（PASS 仍须跨族复审 + 真机目检）+ 跨族复审挂账**，绝不冒充跨族、绝不静默标 done。与 record-capture 我对 codex 立的规矩自洽（同族不替代跨族，但工具全断时诚实降级 + 挂账，非「假装做了」）。

2. **同族末位仍挑出真缝**：两 fresh 镜头（correctness / spec+金牌）揪出 F4 文案过度声称 + 一批金牌强度缺口。correctness 镜头逐条契约保真核过（零 High/Med，装配逻辑扎实），价值在 spec 镜头——fresh-context + 对抗指令即便同族仍有效。

3. **诚实收缩要连产物文案一起诚实**：report-spec #11 五项（开始/结束节点、连线、开始/结束配置）收成三类（节点/连线/节点配置），不仅 GRILL D3 记账——渲染文案原写「画布结构完整」被评审揪为过度声称（F4），改「三类操作均已验证通过；开始/结束节点身份未单独区分（#11 收缩）」。读者只看报告不看 GRILL，文案不诚实 = 过度信任。

4. **金牌反复栽在「含子串 ≠ 形态正确」**（累积第 N 次）：逐类 ✓/✗ 倒置可绿、完整案「警示须缺席/OK 结论须在场」未验、MD 位置只 `includes`——位置比对、枚举两向（在场+缺席）、逐元素形态，都强于 `includes`。金牌纪律：断言要能抓住「反着实现也绿」的回归。
