# report-cleanup-evidence — learn（P7 报告第三增量）

## 教训

1. **数据早在断言里、增量只是 surface**：`countChange` 断言的 `actual` = `"删前→删后"`（`replay-assert.mjs:59`）逐步 期望对实际 表已呈现，本增量把它提成顶层「清理证据」块，兑现 report-spec #9 的 prominence（编辑型用例清理证据要醒目、不埋在断言里）。零新增数据/管道，纯投影 + 缺席零行为差。

2. **codex 连续两轮只揪金牌假信心，实现 diff 干净**：本轮 3 条全是金牌强度问题（MD 位置没验 / HTML 顺序容忍缺步 `iStep<0` 也过 / 缺席零行为差只验 HTML）。累积教训：金牌要验**位置**（块相对顺序）、**形态**（精确结构非含子串）、**双形态**（HTML + MD 都验）。「`includes(子串)`」是最弱断言，位置/顺序类不变量必须用 index 比对且拒绝「前提缺失即通过」的旁路（要求前提锚点存在，如 `iStep>=0`）。

3. **缺席零行为差要 HTML + MD 双验**：块在两形态各有渲染分支，零行为差断言也须覆盖两形态——只验 HTML 会漏 MD 半边（旧模型/空数组仍可能产 MD 空块）。加法碰双形态渲染器的通用补法。
