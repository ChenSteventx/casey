# 账户安全配置

## 目标

- `AI` 中台账户写入现有 `.auth/credentials.json`，并由既有登录预备动作原路径读取。
- 医生站 / Hi 小助只保存安全账户引用与人工就绪声明；真实登录页未采样前，自动登录能力固定为未验证。
- 用户通过 Casey skill 用自然语言发起；底层 CLI 仅从隐藏交互、标准输入或环境读取，不接受账户值和口令参数。
- `account status` 与 `doctor` 只报告存在性、形状和就绪级别，不回显任何值或绝对路径。

## 安全边界

- 所有账户文件必须位于项目 `.auth/`，目录已 gitignored；拒绝符号链接和未知字段。
- POSIX 尽力把目录设为 `0700`、文件设为 `0600`；Windows 明示这是本机文件权限边界，不把 POSIX mode 冒充 ACL。
- 写入采用同目录临时文件后原子替换；错误仅给固定类别，不带输入内容。
- 不连接 fake SUT、fixture 或真实 SUT，不启动浏览器。

## 验收

- 零 SUT 测试证明登录预备动作能读取新写入的中台账户。
- 标准状态输出不含账户、口令或桌面账户引用字面量。
- 医生站 / Hi 小助即使声明 ready，仍报告自动登录未验证、需要人工安全会话。
- 四 OS 文档覆盖 Windows、WSL、Linux、macOS 的安全存储与使用边界。
