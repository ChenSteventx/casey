## 四、设计底线（立项即定，不随方案变）

- **裁判零 LLM（护栏 #15）**：诊断中的 LLM 判读只能是裁判的下游消费者，
  绝不进裁判进程、绝不改四态结论；照 P6 自愈（`lib/heal/`）的合规范式接线。
- **能机械判的不交 LLM**：前后端定责里可确定性判定的信号（5xx、错误信封、
  超时、契约字段缺失 → 后端；请求未发出、参数畸形、200 但渲染断言挂、
  控制台异常 → 前端）做成零 LLM 规则；LLM 只兜「证不出」的那部分，
  与 fail-safe 内核一致。
- **稳定复现靠跨运行比对**，不靠猜——用既有产物（run-history / axes /
  网络取证）的字段做指纹。
- 复用既有网络取证（ADR-0007 按发起方归因），不另起一套采集。
