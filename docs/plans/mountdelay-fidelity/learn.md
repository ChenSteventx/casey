# mountdelay-fidelity learn

1. fake-SUT 浏览器金牌进入隔离后，后续修复不能靠新增共享夹具重新获得 hermetic 合法性；判据单元是
   增量证据，真实 DOM 因果链仍须 route:human。
2. 配置态防线只能加严，不能因兼容路径或 selector 未命中而比无配置路径更早放行。把两个模式写成
   共享 `stableSamples>=3` 的合取关系，比另造两套计时器更容易审计。
3. `page.evaluate` 的兼容返回必须看上下文：无配置时裸长度可承接旧桩；配置占位门时同一裸长度缺少
   占位证据，只能是 unknown。
4. 审查包装器的凭据闸命中术语说明时，应缩小临时审查 diff，而不能删除真实权威文档；同时必须在
   review receipt 解释过滤造成的证据差异。
5. 模型或包装器 `Cancelled` 是 HARNESS_ERROR，不是 REVISE/ACCEPT。只有真实完成的模型输出才能进入
   finding 处置。
6. 审查意见要求“对称”不等于契约要求。先列时间线和布尔包含关系，证明是否真改变授权结果，再决定
   是否加延迟。
