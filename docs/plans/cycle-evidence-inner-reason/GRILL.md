## D0 事实（已核，不是推测）

`lib/teachin/raw-axes-adapter.mjs` 的 `projectAndVerify` 与其 `inspectBinding`
预检，去重后**恰六个**具名拒付码（审校逐条点过全部 `denied(...)`，无第七个）：

| 码 | 触发要点 |
|---|---|
| `RAW_AXES_PROJECTION_INVALID` | 依赖包不可用（缺 raw/resolved 消费者、投影器或裁判适配器）或入参非精确键形状 |
| `RAW_OBSERVATION_AUTHORITY_INVALID` | raw 预检/消费抛错、非 ok、或无可用投影 |
| `RESOLVED_PROJECTION_AUTHORITY_INVALID` | resolved 预检/消费抛错、非 ok、或无可用投影 |
| `RAW_AXES_BINDING_MISMATCH` | 绑定预检不符（capture/case/expected digest、观测计数、**待补计数非零**、resolved 计数）或执行后两侧投影绑定不一致、意图事件规划失败、轴输入构造失败 |
| `RAW_AXES_PROJECTION_FAILED` | 轴投影器抛错或返回非空字符串以外的东西 |
| `VERDICT_EXECUTION_FAILED` | 裁判适配器抛错/非 ok/产物非缓冲区，或证据投影非法 |

四处字符串透传在生产接线下闭合（raw 侧只产第二码、resolved 侧只产第三码，
接线点 `runtime-cycle-adapter.mjs`），注入式其他串必须降格。

## D1 修法（乙路：下沉到发射点）

`return denied(...)` 换成「先通报再返回」的小助手。拒付码的来源分两类
（codex r3 订正，别笼统说「都是本地字面量」）：**12 处是发射点本地字面量；
3 处（预检、raw 消费者、resolved 消费者）是被调方给的动态值——复用既有表达式
已算出的原始值，不新增外来对象读取，并经 D2b 的六码局部归一器落码**。
该文件已有同形先例 `reportFormalRefusal`，照它的通报形制写；但**不得复用
全局归一器**（它会放过全局合法却不属本生产者六码的成员，见 D2b）。

乙路相对甲路（在外层读内层返回对象）省掉的：描述符读取、代理陷阱、抛错
getter、继承属性四类负控；惰性载荷与「被观测探测口」的代理计数钉；以及对
`replay-completion.mjs`（带逐字节钉的文件）的任何改动——**该文件一字不动**。

## D2b 生产者局部归一器（codex r2 阻断二）

`projectAndVerify` 里有 `preflight`、raw 消费者、resolved 消费者三处**动态
拒付透传**（值来自被调方而非本地字面量）。若通报只写硬编码本地码，这些真实
分支落不到正确码；若直接复用全局归一器，它又会放过「全局合法但不属本生产者
六码」的成员（如动作失败码）。故定案：**写一枚精确六码的生产者局部归一器**
——只认 D0 六码，其余一律落兜底成员 `OTHER_REASON`；复用既有表达式已算出的
原始值，不新增外来对象读取。负控至少含一个全局合法但非本生产者六码的成员，
以及一个完全未知串。

## D5 白名单外的失效模式（审校纠正的威胁模型）

白名单外的自由串**不是泄露，是整份边车丢失**：记录投影对 `reason` 走白名单
判定，不命中返回空，`safeEmit` 随即把整批标记中毒、落盘端拒写。所以负控要
断言的是「不中毒 + 降格成兜底成员」，只断言「原串不出现」打不到真正的失效面。
真机若边车干脆没落盘、CLI 报边车模式拒付码，第一嫌疑就是降格漏了某条路径，
别误判成录制失败。

## D6 验收（含可达性证明与三岔判读表）

**可达性证明**（审校补，使纪律更硬）：`replay-completion.mjs` 的三个
`resolved-completion.result-shape` 发射位里，只有结果形状那一条在 canonical
接线下可达——绑定换绑那条因两枚权柄由适配器原样回传恒相等而不可达；
`ok:true` 但字节非缓冲区那条因构造与前置闸而不可达。故今晚边车那条事件必然
对应六码之一，**生产路径上兜底成员不可达**。

**先纠正 v1 的一处错读（codex r2 阻断一）**：内层通报之后，外层那条统一码
**仍会照常再发一次**——结果形状分支本就是正常必达分支。所以正常结果是
「新归因点六码之一 **加** 既有外层码」同时出现，不是三者择一。判读表：

| 边车实得 | 判读 |
|---|---|
| 新归因点=六码之一，随后外层点=统一码 | 验收通过，真因已定位，转入修复 |
| 新归因点=兜底成员 | 实际返回契约与静态核查不符（接线被改或注入非 canonical 依赖）——回去核接线，**不许临时放宽白名单** |
| 无新归因点、只有外层码 | 改动未生效，或某个拒付位漏接助手 |

## D7 诚实预期（审校风险提示，必须让人知道）

**「再录一次」≠「闭环转绿」。** 修完本轮定位到的内层码之后，下一个失败点
极可能落在 `replay-completion.mjs` 的语义证据投影失败路——那里**完全无通报**，
且它产的码（意图覆盖不符、收据模式非法、终态谓词类、拓扑类、实体类、影响类）
**一个都不在**边车拒付码白名单里。届时要么再瞎一次，要么得扩白名单（那才是
真正牵动四层闸的改动）。到闭环绿之间大概率还有两到三个契约。
