# learn · wf-open-preface-notes

## 这轮学到什么

1. **谜面卡住时，先花小钱买观测，再赌修向**。八跑都在盲猜前奏行为；两条 notes 的
   纯诊断契约（零行为差）让下一跑直接带回现场证据——比再猜一轮修向便宜一个量级。
2. **评审方给的 API 修法要先核 API 真伪**：pi 的关切（evaluate 无超时）成立，但它给的
   `page.evaluate(fn, { timeout })` 形在 Playwright 不存在（第二参是 fn 入参）——照抄会
   静默把选项当入参传进页面闭包。采纳关切、换仓内已有先例（EVAL_RACE 竞速）实现，
   并在增量复核里请评审方核替代达意。
3. **诊断代码也要按病态页设防**：给「取证空壳页」写的诊断，自己不能在空壳页上挂 30s
   ——取证工具的超时预算要比被取证的病态更短（3s 竞速让行、降级如实记）。
4. **「零行为差」的最强证法是规范化 diff**（pi 首创于本仓）：把诊断面剥离后与基线逐
   字节比对——比逐点人审判定面强得多，值得进评审提示词模板。
