1. **一份裁定、多个消费者：让位语义的接线要按消费者逐个走完**。compile 侧基数门
   （terminal-coverage-yield）修完后，sign 侧准入验证器是同一冲突的下一个消费者——
   十五跑真产物首次抵门才暴露（「从未走通过」家族续例）。同一已签设计逐消费者接线、
   每个消费者独立契约独立红绿，比一次大改稳。
2. **豁免判据在不同验证器可以更紧**：准入侧比基数门多一条「信封整缺才是让位形」
   （空信封在场=畸形态照拒）——豁免条件按各验证器的既有拒面（c26）取最紧交集，
   fail-closed 姿态随消费者精化而非统一放松。
3. **首轮双 APPROVE 二连**：证据定案 GRILL（承已签设计零新岔口）+ 红面即契约面 +
   突变闭环 + ext4 克隆评审的工艺配方稳定复现。
4. **挂账**：A4 夹具对义务白名单的独立贡献可补一钉（grok 软注记）；replay 段的
   grant/authority 机制是链条下一段（拒了就停如实报）。
