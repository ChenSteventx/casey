# stale-red-admission-refit — 复盘

1. 强制层落地必须当场复跑受影响金牌（护栏 #19 又一实证）：实体准入面 7 月中落地，`p3-compile` 与 `report-diagnostics` 拖到 2026-07-22 才发现陈旧红——期间这两块盲区里若有真回归会被准入红掩盖。
2. 修单前先分辨「义务红」与「脚手架红」：E1 的被证义务是诊断嵌入，不是实体准入——sol 判定改只读白名单信封（更小、零权威）优于为只读导航虚构身份收据；反之 C8 的义务恰是「到达多匹配动作门」，必须铸权放行准入并收紧红因锚（唯一目标行四证），否则准入拒绝能冒充多匹配红。
3. 铸权脚手架三纪律：权威件在 confirm 终写盘后按精确字节生成（任何再写盘=hash mismatch）；临时 prd `wx` 独占 + owner 标识校验清理 + 退出钩子兜异常（硬杀残留下轮 fail-closed 报错、不自动删）；冻结锁生成后 events 字节只读。
4. 不铸权也是修单决策：C4 未 confirm 段与 C4d 篡改段保持无权威件，红因才继续来自 confirm 门（66）与重验闸（65+钉词）——给失败路径补权威反而会把义务红换血。
5. 概述类「自然语言投影」措辞要过 fail-safe 口径：只描述报告清单与四态计数，不声称「已执行」；非全过先声明不得视为通过（codex M2）。布局改版时说明散文不得包含既有顺序钉的栏目词（codex M3 撞词假绿）。
6. 异构分工有效：sol max 出方案判定（含我未想到的「C4d 不铸权」「C8 收紧四证」），codex high 审实施忠实度（抓到 prd 生命周期与措辞四处 Medium）——方案咨询与实施评审分两轮、各司其职。
