## 二、教训

1. **评审日志要读全，不能只读尾段**：codex r3 上半段三条 NOT_FIXED 被漏读，
   r4/r5 只复核了我列的窄范围就误以为收敛——补读才逮回。凡 delta 复审，
   逐条 FIXED/NOT_FIXED 清单必须核完再宣布收敛。
2. **「自证型静态钉」是军备竞赛，止损靠威胁模型不靠更聪明的词法**：C7 六轮被
   合法语法反例连破（注释→字符串→别名正则→对象字面量/debugger→求值期启动→
   转义标识符→as 别名）。终态=机制钉（计数/毒化/模板/\u 禁令/具名导入）+
   诚实威胁模型声明（协作文件回归闸，不防有仓写权的对抗混淆——那种对手改金牌
   本身即可，任何静态门在此威胁下自反）。早声明威胁模型能省四轮。
3. **实现者转述不是证据，日志里的退出码才是**：修复代理两次证据打滑
   （非忠实保真测量、声称未在档的实录）均被真仓评审逮住。评审方给真仓访问
   自己跑验证这条纪律（2026-07-23 定）今晚兑现了完整价值。
4. **观测边车的「零行为差」必须钉到微任务/异常栈粒度**：reportedCall 包裹
   异常身份保留但 settled/queued 反序、栈多一帧——「返回值相同」远不等于
   「字节级控制流等价」。侧通道类改动的等价断言要含时序与栈形。
5. **「不可达分支」挂账要以公开导出面为准**：canonical 编排恒传闭合键 ≠
   生产 API 不可达（index.mjs 公开导出即可直调）。A4 逐生产点归因语义下，
   同形分支不留半接。
6. **威胁模型收窄是合法修法但要三处同步**：M3 收窄后 plan 正文与源码注释
   残留旧强表述被 r3 逮；措辞收窄要全文 grep 清干净。
