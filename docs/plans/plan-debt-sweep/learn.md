1. **审计出的欠账要立刻验「洞是不是真的」**：sign 冻结期 lint 的红跑实锤（裸 `atl_` 字面量现能
   签进冻结 exit 0）把「文档说该有而没有」升格成「fail-open 洞在库」——欠账清洗的优先级判断
   靠红跑，不靠文面。
2. **已签未接线的决议是最便宜的高价值活**：capturedAgainstBuild 的 `?v=` 决议签了五天没人接，
   接线本体十几行。审计的价值之一就是把「签了就忘」捞回来。
3. **同款正则两处镜像 + 注释互指是可接受的中间态**：草拟闸与冻结闸各两行、抽公共件的抽象税
   大于收益；但评审员提醒对——扫描边界（「易变值只在 value」）要在抽公共件时显式化成契约。
4. **对账表治「文档漂移」比改正文便宜且诚实**：设计文档是历史决策记录，就地改写会毁溯源；
   头部对账表让零上下文读者先看偏离再读正文。矛盾正文逐步修是长尾（评审 F5 留案）。
