# learn · wf-open-search-first

## 这轮学到什么

1. **「点不到」要区分三层：没渲染完（时序）、被过滤（视图）、根本不在 DOM（数据时机）**。
   B4 的 open absent 连过三层排查：就绪锚治了时序、页签探针否掉了视图、最后落在数据
   时机——SPA 同址 nav 不重查询、旧卡集里没有新实体。三层的修法完全不同（等待/切页签/
   强制新查询），跳层猜会白做一轮契约。
2. **与冻结金牌共存是硬约束，设计要向它收敛**。首版独立预算撞了冻结 post-nav 金牌的
   两根钉（<20s 上界、必真轮询）；正解不是 amendment 人签，而是把设计精化成双目标
   轮询 + 条件预算——更好的工程恰好也是不动冻结件的工程。
3. **无条件置位的标志就是伪证**：`openSearched = true` 不看 emit 结果，等于把「真发起
   了搜索」弱化成「试图搜索」——pi 逮个正着。任何授予额外预算/权限的标志都应绑定
   动作的真实结果（unique && acted）。
4. **注释词汇碰撞一天踩两次**：结构钉以注释词组为切片界标，实现注释顺嘴复用同一词组
   就误红。写实现注释前先查金牌结构钉的界标词表——已两次实证，该进写作检查单。
5. **评审并集处置的三分法**：可修的立即修（fieldLabel、openSearched）、机制性挂账的
   留在既有账本（预算累加、过滤态互扰）、建议二选一的选代价小且根治的那支。修后
   增量复核（pi delta）比整轮重审省一个数量级。
