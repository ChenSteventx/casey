# `agent-network-code-identity` 复盘

1. 浏览器 `evaluate` 回调是独立执行域。Node 单元替身若直接调用函数，会让模块自由变量继续可见，制造无法在真实 Playwright 成立的假绿。此类门至少要用函数序列化隔离域验证。
2. 身份剖面解析结果必须与动作期模式语义一致。只有字段缺席才可承接 legacy；显式 null、未知值与畸形闭集都应在浏览器前拒绝。
3. 新模式的可信分工应写进摘要域：DOM 负责精确名称和物理句柄，网络信封负责完整集合、编号和平台标识。摘要须覆盖模式、通道、容器和名称选择器；legacy 摘要材料保持原 `listApi` 不变。
4. `ElementHandle` 连续性不等于身份完整性。句柄只封住读后重排与换节点窗口；同名同显示事实的实体替换仍依赖完整网络信封与已签平台标识，最终必须在真机敌意样本中验证。
5. 全仓相邻金牌可能带既有陈旧红。应在基线与分支各跑一次，证明非本差异引入，再在本契约如实挂账；不得改 owner 冻结件或把陈旧红冒充本轮完成。
