1. **挂账同族缝要趁热收**：ingest 契约评审刚建立的判据（CLI 参数在凭据门扫描面外）与修法形态
   （只报字符集 + 原值不回显）还在上下文里，机械镜像到姊妹 CLI 成本极低（六处一轮收口）；
   拖到冷启动就要重付摸底与评审成本。
2. **grep 机械枚举划范围**：以全仓「非法字符」grep 定位六处，范围由机器枚举而非记忆列举——
   sign 的 `signer`/`against-build` 两处就是枚举捞出的（原挂账只记了 caseId 两处）。
3. **改文案前先核冻结金牌的断言面**：`compile-caseid-shape`/`p2-sign` C10 等冻结金牌只钉退出码
   不钉文案（接包前 grep 亲核），零棘轮冲突才动手；若有金牌钉了旧文案，就得走对应契约重冻而非直改。
4. **哨兵三断言模式**：exit 65（拒绝分支）+ 点名「非法字符」（证打中该闸非旁路读失败）+
   不含哨兵（证不回显）——三件缺一则红证不成立（只断退出码会被读失败分支假绿）。
