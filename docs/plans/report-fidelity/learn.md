# learn — report-fidelity（light，2026-07-02）

六阶段全走完（grill 三机械决策 → plan → accept 红先行七红 → loop gate GREEN → codex 三轮 R3 PASS → learn）。沉淀四条：

1. **防泄漏启发式的误伤面要留独立回归向**：`OPAQUE_BLOB` 32+ 长串启发式对纯路径整段误伤，layer3 十二轮硬化期间没人发现——因为金丝雀全是凭据形态、没有「无害长值应保留」的反向案。防御性正则每上一条，配一条「合法值不误杀」的反向锁（F1a 即此类）。
2. **收窄脱敏的正确姿势是复用既有原语**：纯路径旁路不是「跳过检查」而是「换更细粒度的既有检查」（`redactUrlPath` 逐段判）——放行面与拦截面都有既有实现背书，codex 两轮都没在这条上开火。
3. **「元组语义」是投影类逻辑的惯性盲区**：签署字段（版本 × 签署人）是一个证据元组，不是两个独立字段——codex 连打两轮同一主题（同源部分投影 → 跨源拼合）。凡把多字段从证据源投影到展示层，问三个问题：字段间有没有联合语义？部分可得时展示什么？两源冲突时会不会拼出谁都没说过的组合？
4. **actual 回填的口径纪律**：每 kind 的 actual 是「该断言语义下的实测锚」不是「随手可得的值」——取证类给归因计数（0 也是证据）、比较类给被比对象、未实现恒 null 不硬凑。`ok` 判定一字不动是加性红线（golden 每案双断 ok+actual 即为此）。

配套：`--expected` 接线兑现了 layer3 时代「押后真机 bring-up」的原注取舍——押后项要带「兑现条件」，条件成立时主动回收（本轮由首份真机报告体检触发）。
