# learn — cred-route-mask（direct，2026-07-03）

三条沉淀：

1. **门的误伤是护栏在自证，处置要「加投影不减门」**：`token` 路由名命中是关键词扫描按设计 fail-closed——正确处置是落盘投影处打码（信息留痕迹、门零弱化），不是给门开豁免。U3「门配对」把这个原则钉成机器事实：原样必拦、打码必过。
2. **修一个落盘口时顺手盘点全部落盘口**：本轮 GRILL 原 claim「query 携凭据仍由门拦」对 axes 不成立——axes 从 P5 起就是漏网落盘口（无门、query 原样）。codex 抓出后补门 + leaky 场景退桩红。经验：凭据面改动的评审包应显式列「全部落盘口 × 是否过门」矩阵，别让 claim 替代盘点。
3. **hermetic 夹具能精确复现真机事故**：夹具补「先取票再开流」真机同款时序后，C2 在 hermetic 里逐字复现了真机门拦报错——事故进考场，修复才有回归锁。真机撞到的每个坑都值得问一句「夹具能演吗」。
