## 这轮学到什么

1. **同类竞态要按「面」清点，不要按「点」补**。列表页渲染尾巴一天连咬四个锚点
   （登录表单、create 入口、open 文本、delete 搜索框）——第二处出现时就该把
   「nav 后首锚」当一个面盘点全链路，一次契约收口；实际走成了三个契约逐点补。
   已在 plan 非目标里立规：再冒第四处，升级「nav 后首锚统一就绪协议」，不再逐点。
2. **预算累加是硬化的对价**。每加一个 15s 有界锚，失败路径最坏时长就抬一截；
   两轮评审的 pi Medium 都指向同一账本（当前估算最坏 ~85–100s vs 看门狗 120s）。
   硬化到第 N 处时，「预算共享池」比「每锚独立预算」更对——挂账为升级方向。
3. **结构钉的切片边界会被自己的注释撞红**。S5 以「容器归属闸」注释为切片上界，
   实现注释里顺嘴提了同一词组就误红——结构钉与实现注释之间存在词汇耦合，
   写实现注释时要避开结构钉的界标词（PRD notes 已立此纪律）。
4. **评审方的双态复跑能白捡陈旧红**。pi 顺手把闸直邻的 `wf-open-smoke` 金牌在
   HEAD 与基线各跑一遍，逮到既存陈旧红（原子数钉 18 vs 26）——「基线同红」一步
   就把责任归属定清了。这枚陈旧红连带一个真空洞：open 容器归属闸的 fail-closed
   面眼下没有活着的金牌在钉（另期重钉）。
