# 智能体工具首纵切集成计划

## 目标

把 `da7b2f1` 中七个智能体工具原子的有效实现重放到 `dev@5cd75d5`，解决其与最新删除和报告信任边界的冲突，不改变既有裁判、人签或正式报告语义。

## 步骤

1. 在目标基线上冻结候选分支已有的两条零 `SUT` 验收和候选 flow，并验证实现缺席时确实为红。
2. 重放候选提交，逐文件核对 `compile-atoms`、`replay-actions`、原子注册表与共享金牌的冲突。
3. 对删除动作保留目标基线的因果确认弹层与目标归零语义；七个原子候选仍需参数和身份门 fail-closed。
4. 只运行冻结的零 `SUT` 验收、静态语法检查、checksum 核验和明确的纯函数回归。
5. 记录尚缺的真机编译、人签、回放、录屏、视觉复核和独立 HTML，不把集成绿当真机完成。

## 验收点

1. 两条候选零 `SUT` 金牌在实现缺席时为红，重放后全部为绿。
2. 七个原子都进入编译分派表，命名编译原子数从 18 增至 25；未知原子仍拒绝。
3. `agent_tool_add` 候选顺序、创建与清理模板绑定、事件 schema 兼容性保持不变。
4. `agent.delete` 不回退到全页确认按钮；多匹配、缺上下文、列表仍加载或删除后未稳定归零均 fail-closed，后置检查只消费同次触发和确认链。
5. 冻结验收 checksum 与契约一致，零 `SUT` 结果不替代真机行为证据。
