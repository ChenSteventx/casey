# regress 智能体工具首纵切迁移计划

## 目标

只读提取 `regress_autotest` 的业务语义，把 `agent_tool_add` 迁为 Casey 可编译的候选纵切。遗产代码、旧报告、旧录屏、trace、真实地址和凭据一律不复制。

首纵切包含七个此前只有注册表声明、没有 Casey 编译知识的原子：

1. `agent.create`
2. `agent.openToolPicker`
3. `picker.search`
4. `picker.expandPrimary`
5. `picker.selectFirstTool`
6. `agent.confirmToolPicker`
7. `agent.delete`

已有的 `login`、`nav.agentManagement` 与 `assert.*` 沿用 Casey 现有接缝。

## 实现边界

- 新增纯函数配方层，统一参数校验、Reserved Prefix（保留前缀）实体模板和事件配方；编译执行层不得另写一套参数默认值。
- 七个原子均须进入编译分派表并产出真实事件；不能用注册表占位或空函数凑数。
- 工具选择器的点击必须限定到可见工具对话框或详情页工具区；多匹配、缺席、动作后置回读失败均 fail-closed（安全失败）。
- `agent.delete` 必须把搜索值、目标记录、因果确认弹层和删除后精确归零绑定起来；不能复用“全页最后一个确定”。
- 本轮只运行静态、schema 和纯函数验收，不启动或连接任何假被测系统、夹具、浏览器或真实被测系统。
- 真机编译、签署、回放、录屏、视觉复核与单用例 HTML 不在本工作树执行，全部列为 `route:human`。没有这些证据不得宣称行为完成。

## 验收点

1. 10 条智能体工具遗产清单名称准确且无旧产物复制。
2. 七个原子都通过参数反例与事件配方检查；实体名和编码均为 `atl_` 模板，事件不含地址或凭据。
3. 七个原子都被 `isCompilableAtom` 接受，命名编译原子数从 18 增至 25；既有未知原子仍拒绝。
4. `agent_tool_add` 配方顺序完整，清理目标与创建目标使用同一模板；遗漏创建上下文时 `agent.delete` 必须拒绝。
5. 事件符合冻结 `events.schema` 的既有动作与字段，不扩动作枚举。
6. 真机行为保真度列为待人裁决，不用零 SUT 结果替代真实验证。

## 公开树移植边界

公开发布树有独立的正式交付、CEF 与分发能力。本分支只提供原子配方、编译/回放动作接缝、零 SUT 验收与迁移清单；移植时应逐提交挑拣并按公开树当前差异重放，禁止整树覆盖。
