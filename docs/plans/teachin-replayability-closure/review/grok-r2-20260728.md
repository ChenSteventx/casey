| 观察 | 严重度 | 说明 |

| **`BASELINE_LEDGER` 进程级 Map** | 卫生 | observe 成功、verify 未消费时 key 残留；同 key 后观察覆盖。无跨进程伪造面，技术探索可接受。 |
