# wf-open-smoke — learn（direct，codex 两轮 R2 PASS）

1. **「全页唯一」不等于「身份正确」**：text-exact 唯一命中还可能是同名非行控件——点击身份门要加
   容器归属维度（命中须在记录容器内）。碰撞反例可以零夹具成本造（拿页面既有控件名当 openName），
   红跑实锤「真点了按钮」比论证有力。
2. **只读原子的「只读」要双向钉**：正向（动作 ⊆ nav/click、原子名反词）+ 身份闭环（打开的是那条
   ——详情渲染被打开名 + 签入身份断言），否则「进了某个详情页」就能绿。
3. **自己加的闸会咬到自己的用例——这是闸在工作**：身份断言想用 `atl_目录CRUD_a` 字面量，被两小时
   前 plan-debt-sweep 加的冻结 lint 拒了——改用去前缀子串。这正是该 lint F3 记档的误伤面的第一个
   实证：真机用例按名断身份时同样要用非前缀段（或将来议模板化/例外机制）。
4. **飞轮第五条的机制缝 = 1**（容器归属闸），延续递减序（3→1→0→1）：零缝不是常态，暖场用例也能
   暴露真闸缺口——「递减假设」的价值在于让每条新缝都值得单独看。
