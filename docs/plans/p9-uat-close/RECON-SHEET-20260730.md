## 需要你做的三问（在真机上）

前置：只用 autotest 账号；用带保留前缀的新工作流，别碰既有数据。

走到「新建工作流 → 确认 → 保存 → 发布 → 点历史版本」，浮层打开后：

**问一：浮层里有没有一个写着「关闭」的按钮？**
- 有 → 记下它的可访问名原文（鼠标悬停或看按钮上的字），以及浮层内同样长相的按钮有几个（正常应为 1 个）。**有这条，后面两问都能省。**
- 没有 → 看右上角有没有关闭图标（叉号）；记它是什么标签、有没有可访问名（悬停有没有提示文字）。

**问二：这个关闭控件有没有可见文字或可访问名？**
- 这条是硬门：点击类事件必须能靠文字或可访问名定位，**两样都没有的控件根本写不进用例**（被冻结的事件规范拦着）。若确实两样都没有，就要换关闭路径（比如点遮罩）。

**问三：点关闭之后，「创建时间」这几个字是从页面里消失了，还是只是看不见了？**
- 最简单的判法：关掉浮层后按 `Ctrl+F` 搜「创建时间」，看还搜不搜得到。
- 搜不到 = 真的移除了 → 现有断言写法正确，不用改；
- 还搜得到但屏幕上看不见 = 只是隐藏 → 现有断言会一直误判红，需要改成「可见数为零」的判法。
